# Schema Change Proposals

Store database design documents in this directory using the naming convention `<yyyy-mm-dd>-short-title.md`. Each proposal should include:

1. Summary and motivation
2. Detailed schema changes (tables, columns, indexes)
3. Rollout plan and estimated impact
4. Rollback plan
5. Testing/verification approach

Proposals must be reviewed and explicitly approved before the associated migration is implemented in `/supabase`.
